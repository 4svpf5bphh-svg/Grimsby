GRIMSBY PWA

To install on iPhone:
1. Upload this folder to any HTTPS static host.
2. Open the hosted URL in Safari.
3. Tap Share → Add to Home Screen.
4. Launch Grimsby from the Home Screen icon.

Important:
- The app works offline after the first successful load.
- Saved character data remains tied to the same website address/origin.
- When updating the app, keep using the same hosted URL so Grimsby's saved state remains available.
